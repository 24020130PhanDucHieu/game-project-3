Hướng dẫn thi đấu

Luật thi đấu Ô Ăn Tù Tì V2 trên bàn cờ 9×9 và tài liệu lập trình bot.

1. Thể thức thi đấu & Mục tiêu chiến thắng

Trận đấu diễn ra trên bàn cờ lưới 9×9 (81 ô) giữa hai đội Đỏ và Xanh:

  • Lực lượng ban đầu: Mỗi đội sở hữu 9 quân cờ gồm 3 Búa, 3 Bao, 3 Kéo. Đội Đỏ xuất phát ở hàng 7, Đội Xanh xuất phát ở hàng 1.
  • Căn cứ đối phương: Căn cứ Đội Xanh nằm tại ô [8, 0] (mục tiêu của Đỏ). Căn cứ Đội Đỏ nằm tại ô [0, 8] (mục tiêu của Xanh).
  • Điều kiện thắng hiệp: Đưa một quân bất kỳ đột kích vào ô căn cứ của đối phương trước, HOẶC tiêu diệt toàn bộ 9 quân của đối phương.
  • Thể thức trận Bo5: Đấu tối đa 5 hiệp; đội đầu tiên thắng đủ 3 hiệp sẽ giành chiến thắng chung cuộc. Không có kết quả hòa.

2. Quy tắc di chuyển & Giao tranh

Hai đội luân phiên ra quyết định từng nước đi (Đội đi trước hoán đổi qua từng hiệp):

  • Cơ chế ra quyết định: Bot trả về một trong ba loại quân "ROCK", "PAPER", hoặc "SCISSORS". Hệ thống sẽ điều phối quân tương ứng tiến lên hoặc tấn công kẻ địch lân cận.
  • Quy tắc khắc chế: Búa (ROCK) thắng Kéo · Kéo (SCISSORS) thắng Bao · Bao (PAPER) thắng Búa
  • Va chạm cùng loại: Khi hai quân cùng loại chạm nhau, quân phòng thủ (đang đứng yên tại ô) luôn chiến thắng và tiêu diệt quân tấn công.
  • Ô đặc biệt (nếu có): Ô dịch chuyển tức thời (Portal), Ô tiến hóa (Evolve) hoặc Ô bẫy (Trap) ở các vòng nâng cao theo cấu hình Ban tổ chức.

3. Cấu trúc mã nguồn Bot (Python & C++)

Bot nộp bài cần hỗ trợ một trong hai ngôn ngữ chuẩn sau:

Python 3 (Hàm chuẩn)
def decide_move(game_state):
    # game_state: remaining_cards, my_pieces, opponent_pieces, turn_number...
    cards = game_state.get("remaining_cards", {})
    available = [c for c, count in cards.items() if count > 0]
    return available[0] if available else "ROCK"
C++17 (STDIN / STDOUT)
#include <iostream>
#include <string>

int main() {
    std::string state_line;
    if (std::getline(std::cin, state_line)) {
        std::cout << "ROCK" << std::endl;
    }
    return 0;
}

4. Môi trường Sandbox & Giới hạn tài nguyên

Mọi bot thi đấu được thực thi tự động trong môi trường hộp cát độc lập:

  • Thời gian thực thi: Tối đa 1.0 giây (1000 ms) cho mỗi lượt gọi hàm/nước đi. Quá thời gian (Time Limit Exceeded - TLE) sẽ bị xử thua hiệp đấu.
  • Bộ nhớ cho phép: Tối đa 64 MB RAM.
  • An toàn mã nguồn: Bị cấm gọi lệnh hệ thống, ghi file hoặc truy cập mạng Internet. Vi phạm sẽ bị máy chấm ngắt ngay lập tức.
  • Bảo toàn ngoại tuyến: Khi phòng thi mất kết nối mạng, bài nộp được lưu cục bộ trên trình duyệt và tự động đồng bộ khi có kết nối trở lại.

🐳 5. Hướng dẫn đóng gói Bot bằng Docker cho Sinh viên

Đóng gói bot bằng Docker giúp đảm bảo thuật toán của bạn chạy đồng nhất 100% giữa máy cá nhân và hệ thống máy chủ chấm thi BOT ARENA.

Bước 1: Chuẩn bị mã nguồn

Đặt file bot.py hoặc bot.cpp cùng file Dockerfile trong thư mục dự án của đội.

Bước 2: Xây dựng Docker Image

Chạy lệnh terminal:
docker build -t my-arena-bot:v1 .

Bước 3: Chạy thử cục bộ

Thử nghiệm với dữ liệu giả lập:
docker run --rm -i --network=none my-arena-bot:v1

Dockerfile mẫu cho Python (Python 3.10) 
# Sử dụng base image nhẹ chuẩn bảo mật
FROM python:3.10-slim

WORKDIR /app

# Sao chép mã nguồn bot vào container
COPY bot.py .

# Chạy với quyền người dùng không đặc quyền (non-root) để bảo mật
USER nobody

# Lệnh khởi chạy bot
ENTRYPOINT ["python", "-u", "bot.py"]
Dockerfile mẫu cho C++ (Multi-stage GCC 12) 
# Stage 1: Biên dịch mã nguồn C++ với tối ưu -O3
FROM gcc:12-bullseye AS builder
WORKDIR /src
COPY bot.cpp .
RUN g++ -O3 -std=c++17 bot.cpp -o bot && strip bot

# Stage 2: Runtime image siêu nhẹ và an toàn
FROM debian:bullseye-slim
WORKDIR /app
COPY --from=builder /src/bot /app/bot
USER nobody
ENTRYPOINT ["/app/bot"]
